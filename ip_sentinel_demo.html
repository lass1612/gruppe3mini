Sikkerhedsforanstaltninger

✓SQL Injection: parameteriserede SQL-forespørgsler i backend-eksemplet.
✓XSS: brugerdata indsættes med textContent og valideres.
✓Inputvalidering: IP- og MAC-format kontrolleres før data gemmes.
✓Least privilege: webserveren bør køre uden root; kun Scapy-delen får nødvendig netværkskapabilitet.
✓Autentificering: bør tilføjes før systemet eksponeres uden for et lukket laboratorienetværk.
✓Audit log: scanninger og alarmer logges med tidsstempel.

Scapy – scanner til Raspberry Pi

from scapy.all import ARP, Ether, srp def scan_network(cidr): arp = ARP(pdst=cidr) ether = Ether(dst="ff:ff:ff:ff:ff:ff") packet = ether / arp answered = srp(packet, timeout=2, verbose=False)[0] devices = [] for _, response in answered: devices.append({ "ip": response.psrc, "mac": response.hwsrc.lower() }) return devices

import sqlite3 def add_reserved_ip(ip, name, mac, owner): with sqlite3.connect("ip_sentinel.db") as db: db.execute( """ INSERT INTO reserved_ips (ip, name, mac, owner) VALUES (?, ?, ?, ?) """, (ip, name, mac, owner) ) db.commit() # ? placeholders = parameteriseret query # Brugerinput bliver IKKE bygget direkte ind i SQL-strengen.

Forslag til API mellem HTML og Python

GET /api/reservations -> hent reserverede IP-adresser POST /api/reservations -> opret reservation DELETE /api/reservations/:ip -> slet reservation POST /api/scan -> kør Scapy scan GET /api/scans -> hent scan-historik GET /api/alerts -> hent alarmer Scan-flow: 1. HTML sender POST /api/scan 2. Python kalder scan_network(cidr) 3. Fundne IP/MAC sammenlignes med SQLite 4. Ukendt IP eller forkert MAC markeres som alarm 5. Resultat returneres som JSON 6. Webinterfacet viser status og gemmer hændelsen i loggen
